# Видео-продакшн сайт (Flask)

Это стартовый сайт для видеопродакшна: стиль — минимализм/типографика.

## Запуск

```bash
cd kinoprod
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте: http://127.0.0.1:5000
